# review.blackrainbow.la

User GitHub Pages site for Black Rainbow client previews.

Once DNS is set (`review` CNAME → `jhelf.github.io`), every project Pages repo under `jhelf` is also served at:

`https://review.blackrainbow.la/<repo>/`

Do not add a custom domain on the individual `*-review` repos, or they will stop inheriting this host.
